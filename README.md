# student-performance-system
# Студенттердің үлгерімін есепке алу жүйесі

## Жоба мақсаты

Бұл жобаның мақсаты — студенттердің оқу үлгерімін есепке алуға арналған веб-қосымша әзірлеу. Жүйе арқылы студенттер туралы ақпаратты сақтауға, пәндер бойынша бағаларды енгізуге, орташа балды есептеуге және оқу нәтижелерін бақылауға болады.

## Негізгі мүмкіндіктері

- Пайдаланушыны тіркеу және жүйеге кіру
- Студенттер туралы мәліметтерді қосу, қарау, өңдеу және жою
- Пәндер тізімін басқару
- Студенттердің бағаларын есепке алу
- Орташа балды есептеу
- Студенттерді іздеу және бағалары бойынша сүзу

## Қолданылатын технологиялар

HTML, CSS, JavaScript, PHP, MySQL, Git және GitHub.

## Дерекқор құрылымы

Жоба төрт кестеден тұрады: users, students, subjects және grades.

## Жоба кезеңдері

8–15-апталар аралығында жоспарлау, интерфейс әзірлеу, серверлік логика, дерекқор, авторизация, CRUD операциялары, іздеу, қауіпсіздік және тестілеу жұмыстары орындалады.
