# Студенттердің үлгерімін есепке алу жүйесі

## Жоба туралы

Студенттердің үлгерімін есепке алу жүйесі — студенттердің оқу үлгерімі, пәндері және бағалары туралы ақпаратты сақтауға және басқаруға арналған веб-қосымша. Жоба PHP бағдарламалау тілі мен MySQL дерекқорын қолдану арқылы әзірленеді.

## Жобаның мақсаты

Жобаның мақсаты — студенттердің үлгерімі туралы мәліметтерді бір жүйеде жинақтау, бағаларды есепке алу және оқу нәтижелерін бақылауды жеңілдету.

## Жобаның негізгі мүмкіндіктері

Студенттер туралы мәліметтерді қосу, қарау, өңдеу және жою
Пайдаланушыларды тіркеу және жүйеге кіру
Пәндер туралы ақпаратты басқару
Студенттердің бағаларын енгізу және өзгерту 
Студенттердің орташа балын есептеу
Студенттерді аты-жөні бойынша іздеу
Бағалар бойынша сүзу және сұрыптау
Пайдаланушы рөліне сәйкес қолжетімділікті басқару
## Қолданылатын технологиялар
HTML — веб-беттің құрылымын жасау
CSS — интерфейстің дизайнын әзірлеу
JavaScript — интерфейске интерактивтілік қосу
PHP — серверлік логиканы жүзеге асыру
MySQL — мәліметтерді сақтау және басқару
Git және GitHub — жобаның нұсқаларын сақтау
## Негізгі беттер
index.php — басты бет
register.php — тіркелу беті
login.php — жүйеге кіру беті
dashboard.php — басқару панелі
students.php — студенттер туралы мәліметтер
subjects.php — пәндер тізімі
grades.php — бағаларды басқару
profile.php — пайдаланушы профилі
logout.php — жүйеден шығу
## Дерекқор құрылымы
Жоба төрт негізгі кестеден тұрады
users — пайдаланушылар туралы ақпарат
students — студенттер туралы ақпарат
subjects — пәндер туралы ақпарат
grades — студенттердің бағалары туралы ақпарат
grades кестесі students және subjects кестелерімен сыртқы кілттер арқылы байланысады

## Күтілетін нәтиже

Жоба нәтижесінде студенттердің оқу үлгерімін басқаруға, бағаларын есепке алуға, орташа балын есептеуге және қажетті ақпаратты жылдам іздеуге мүмкіндік беретін веб-қосымшаның құрылымы әзірленеді.
